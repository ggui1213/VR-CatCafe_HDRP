# 猫条与 VR 喂猫

场景：`Assets/Scenes/CoffeeShopFinal.unity`，根对象 `Cat Feeding System`。
模型预制体：`Assets/Cat/Treats/Creamy Cat Treat.prefab`。约 17 cm 高，包含可编辑包装网格、HDRP 材质、标签、撕口、膏体、抓取碰撞体与抓握姿态。
包装主体另有标准 OBJ：`Assets/Cat/Treats/SqueezeSachet.obj`，可在 Blender 等建模软件中继续修改；完整包装装饰和交互配置在预制体中。

## 玩家操作

1. 抬起左手，掌心朝向自己，显示腕部菜单。
2. 用空闲手的射线指向 **Offer creamy treat**，按食指扳机确认。
3. 猫条出现在左腕旁；空闲手靠近后按住 **Grip（侧握键）**拿起。
4. 附近可到达的猫会走近，在玩家前方分散坐下，注视猫条，轻声喵叫和呼噜。
5. 将开口缓慢送到一只猫的嘴前约 5–13 cm，轻扣**食指扳机**挤出膏体。扳机力度控制挤压、消耗与轻微震动。
6. 移开猫条或松开扳机即停止喂食。松开侧握键收起；再次从菜单领取新猫条。

无需占用移动摇杆或系统菜单键。右手拿猫条时左手仍可抚摸猫；拿猫条的手暂时关闭抚摸接触，避免误触两种行为。

## 猫的反应

- 默认吸引半径 5 m，最多四个前方座位；只接受完整 NavMesh 路径，座位间隔至少 42 cm。玩家明显移动或转向后重新安排座位。
- 保留起身、转身、行走、坐下过渡，不让坐着的猫直接平移或旋转。
- 等待时复用 `MeowSit` 与素材包 `Meow Hungry 1–4`，各猫错开叫声时间。
- 吃猫条时保持坐姿：从 `Cat_Drink2` 复制下颌、下唇、舌头曲线，使用 `Treat Mouth` 局部动画层，不覆盖身体。
- 进食增加幸福度、呼噜和柔和眯眼；吃够一小份后播放 `Cat_Sit_Lick_Paw_R` 舔爪收尾，18 秒后才会再接受新一轮邀请。
- 一次只允许一只猫消耗零食。远离嘴、快速挥手、不扣扳机、包内无食物时均不会进食。
- 已在高处跳跃、休息的猫会等到回到地面后再响应，避免瞬移和打断跳跃。

## 调整与验证

- `CatTreatTube`：吸引半径、进食距离、消耗速度。
- `CatTreatFeeding`：每只猫的满足量、冷却时间、嘴部定位点。
- `WristTreatMenu`：腕部位置、掌心朝向检测、菜单显示。
- Unity 菜单 **Cat Cafe → Verify Cat Feeding**：从编辑模式启动真实 XR 抓取和导航验证，覆盖喂食、停止、距离拒绝、耗尽、松手和重新领取；验证结束自动退出运行模式。
- **Cat Cafe → Preview Treat Model** 可临时预览模型，**Close Treat Model Preview** 清理预览。

编辑器流程验证已通过。菜单抬腕角度、手持触感和震动强度仍应在 VR 头显中确认。
